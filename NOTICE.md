Upstream model, tokenizer, numerical/runtime libraries, build tools and notice texts remain their authors' work under their own terms. [LOFRANO TECNOLOGIA](https://lofranotecnologia.com.br) is the project publisher.

The source and wheel carry full collected notices under `src/local_semantic_atlas/_data/notices/` and provenance records under `_data/provenance/`; an installed wheel exposes the same `_data` tree via `importlib.resources.files('local_semantic_atlas')`. `notice-inventory-all.json` records every bundled notice file's actual byte length and SHA-256. The 24-entry development wheel manifest combines the 22 exact original official-PyPI wheel records and the two qualified setuptools/wheel backend artifacts. The runtime lock uses 20 entries, omitting build, pyproject_hooks and the two build backends. Locks preserve exact qualified versions and actual hashes, rather than newly resolving transitive versions.

The fixed `intfloat/multilingual-e5-small` model revision is `614241f622f53c4eeff9890bdc4f31cfecc418b3`. The upstream model card declares MIT and contains the original citations and usage context. `prepare-model` retains that actual README alongside all selected configuration files and verified runtime artifacts. The immutable artifact manifest and upstream metadata record official paths, revision, lengths and hashes. No model weights or dependency wheels are committed or included in the original source distribution; the explicit preparation build fetches them separately under their own terms. The final Docker image contains the separately fetched model and installed libraries and must retain their notices; this source qualification does not certify arbitrary future binary/model bundles.

The tokenizers 0.23.3 source archive is checksum recorded, with its full Apache 2.0 text and exact Cargo.lock/TOML files retained. Its Rust core reports 0.23.2 while Python bindings report 0.23.3; these are not conflated. The conservative closure records 151 checksum-verified registry crates and 306 actual notice files, including packages that may not be linked into the wheel. This is not a proven wheel link graph or source-to-wheel reproduction. defmt-parser declares MIT OR Apache-2.0 but ships no standalone notice file; its actual manifest evidence remains in the closure record.

Flatbuffers' actual wheel declares Apache 2.0 and supplies a Google copyright/license header; the collected full official Apache 2.0 text supplements that evidence. A version-matched GitHub release tag returned 404, so exact upstream-source correspondence remains unverified. Historical supplemental records retain their earlier pending status; the later flatbuffers supplement and conservative Rust-closure records give the subsequent evidence without silently rewriting history.

NumPy and ONNX Runtime include their actual bundled component notices. Build backend notices include actual setuptools vendored licenses and wheel's license; they do not imply these tools are in the artifact-only runtime. The pinned official Python container has its own Python/OS components and terms. No blanket MIT, universal legal-closure, or reproducible-native-build claim is made for third-party components.
