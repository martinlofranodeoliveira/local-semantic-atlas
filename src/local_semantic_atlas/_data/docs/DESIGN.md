# Static retrieval report

Approved direction: a compact printed research sheet for reading and audit, not a SaaS dashboard. A quiet warm paper surface, dark ink, restrained teal rules, serif reading title and native system body text make the ranked table the first substantial content. This is a local export that intentionally uses installed fonts and requires no font download.

Use one continuous document: title and semantic status, ranked table or explicit empty/error paragraph, then provenance. Table scores align right with tabular numerals and retain Python's round-trippable float representation. IDs and hashes use monospace because they are literal identifiers. Long metadata wraps; tables may scroll horizontally at narrow widths; print removes decorative spacing. There is no motion, scripting, card grid, imagery, graph or invented metric. Source-level semantic checks are evidence; visual/browser accessibility remains unverified.
